Připojení WooCommerce

Primární cesta pro první import: plugin + API. Ruční import zůstává jako nouzová varianta mimo tento dialog.

Postup
  1. Nainstaluj plugin Viki Connector 0.8 do WordPressu.
  2. V pluginu zkopíruj token a vlož jej sem spolu s URL webu.
  3. Klikni na Uložit připojení a potom Ověřit připojení.
  4. Po úspěšném ověření spusť První import.
